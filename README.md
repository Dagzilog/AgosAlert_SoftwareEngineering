> *Funtions:*
**client/:** Handles client-side logic or communication.
**model/:** Contains data models and entity structures.
**repository/:** Manages data access, database operations, or persistence logic.
**service/:** Houses the core business logic of the application.
**ui/:** Manages the user interface and presentation layers.
**App.java:** The main entry point of the Java application.
**pom.xml:** Maven configuration file managing project dependencies and builds.
